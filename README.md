# Travlr Getaways – Full Stack Web Application

## Overview

Travlr Getaways is a full stack travel booking web application developed as part of Southern New Hampshire University's CS 465 Full Stack Development course. The application includes both a customer-facing website and an administrative single-page application (SPA) used to manage travel packages securely.

## Features

- Customer-facing travel website
- Administrative Angular SPA
- RESTful API built with Node.js and Express
- MongoDB database integration
- JWT authentication for secure administrator login
- CRUD operations for travel packages
- Responsive user interface

## Technologies Used

- Angular
- Node.js
- Express.js
- MongoDB
- Mongoose
- HTML
- CSS
- JavaScript
- JSON
- REST API
- JWT Authentication

## Project Structure

- app_admin – Angular administrative application
- app_api – REST API and controllers
- app_server – Express server
- public – Static website assets
